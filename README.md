## 1. make.fun 是什么，钱从哪来？

make.fun 是个编程赏金竞赛平台。平时用 Codex、Claude Code 或 Cursor 写代码？带着你顺手的工具就能参赛。每场比赛都有任务、截止时间和 USDC 奖金。打开赛题先看三件事：交什么、怎么评、几点截止。

比赛的奖款锁在 Solana 链上的托管里，锁定情况可以在链上核验。评审结束后，获奖者可以把 USDC 领到自己的 Solana 钱包。

我参加的 **bring-the-humans-02** 奖池是 **1000 美元**，按通过审核的真实注册数排名，**前 50 名有奖**。

## 2. 三步注册并准备收款

1. **先点[我的推荐链接](https://make.fun/r/051v2c77)**。用它第一次打开 make.fun，再找注册或登录入口。如果先从搜索结果进了官网，之后补点链接也改不了推荐归属。 如果注册时看到推荐码输入框，也可以直接填 `051v2c77`。
2. **在登录页选 GitHub、Google 或钱包。** 用 GitHub 或 Google 时，看看授权页选的是工作号还是私人号。用钱包时，在弹窗里确认选中的账户。授权后回到 make.fun，确认已登录。如果还停在登录页，看看浏览器是不是拦了弹窗，或者授权还没完成。
3. **登录后找账户里的钱包绑定入口。** 按页面提示连接自己能控制的 Solana 钱包，再核对页面上的收款地址。用 GitHub 或 Google 登录容易漏掉这一步。用钱包登录也要确认绑定的地址就是你准备用来领 USDC 的地址。

## 3. 怎么挑第一单？

- **先看门票，优先挑零门票。** 从比赛列表点进详情，找参赛费用或报名条件。看到要付费入场，就先看下一场，找个能先把开发到提交走一遍的题。
- **看奖金发到第几名，每档发多少。** 在奖金分配里记下总奖池、最后一个有奖的名次和对应金额。只奖前几名、提交又多的热门单，可以先跳过。
- **把提交数和剩余时间一起看。** 看提交数和截止时间，留意时区。提交少可能是竞争小，也可能是题目难，先翻一下交付要求。估时间时把开发、测试、检查和签名都算进去。时间只够写代码的话，换一场。
- **挑一个你能讲清楚改动的任务。** 点开交付要求，看看用什么技术栈、要交哪些东西、怎么判定完成。新手容易写完代码才发现少交了一项。优先选自己熟悉、范围明确、能在本地验证的题。

## 4. 让 agent 干活的流水线

1. **拉取比赛 kit。** 找到赛题里的获取步骤，按当场比赛给的命令操作。让 agent 先读题，列出任务、交付物和检查方式。
2. **确认开赛后，再开录制会话写代码。** 让 agent 在这个会话里动手。你来审查改动、验证结果，也要亲自对作品做出真实修改。官方模板可以拿来起步，别原样抄来交差。
3. **先在本地过一遍。** 看代码改了什么，跑项目已有的测试或构建，再按赛题要求亲手走一遍主要操作。
4. **跑 `kit check`。** 有报错就按提示修，改完重跑，再核对提交材料。
5. **用钱包签名提交。** 照比赛页面的提示签名，赶在截止前确认页面显示提交成功。

## 5. 钱怎么到账？

结果出来后，先看自己的名次和对应奖金。获奖后，按比赛页提示发起领取（claim），用自己的 Solana 钱包签名。等交易确认，再到钱包里查看从托管发过来的 USDC。

## 6. 实话与风险

多数单拿不到钱。把读题、改代码、测试和提交的时间都算上，挑个即使没拿到奖金也愿意做的小题。

别刷注册。自注册、同 IP 注册和闲号都不算有效注册，还可能被取消资格。把链接发给真想参赛的开发者，让他们自己注册。

## 7. FAQ

**一定要用某个指定的 agent 吗？**  
用你顺手的 Codex、Claude Code 或 Cursor 就行。怎么录制、交什么，先看当场赛题说明。

**能拿官方模板参赛吗？**  
可以用模板起步。开赛后再开录制会话，在里面做出自己的真实修改，最后按任务要求自检。

**`kit check` 通过就能拿到赏金吗？**  
检查通过后还得签名提交。能不能拿到 USDC，要等评审结果和获奖名次出来。

**我已经直接访问过 make.fun，再点推荐链接还算吗？**  
平台按首次触达锁定归属。第一次打开时如果走的是别的入口，后来点链接也改不了归属。

**提交被拒了怎么办？**  
先看提交页显示的原因。如果是检查报错或缺材料，按提示修正，再跑一遍 `kit check`。如果赛题允许重交，就在截止前重新签名提交，回到比赛页确认状态。
